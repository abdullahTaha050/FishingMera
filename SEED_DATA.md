# Sakarya/Kocaeli seed provenance

Version `sakarya-kocaeli-2026.08.23.1` contains 18 records. Coordinate evidence is a direct OpenStreetMap object URL collected on 23 August 2026; fishing evidence is stored separately and never upgrades a record to `VERIFIED`.

- `WEB_DISCOVERED` means a named area has web fishing evidence but no Mera community verification.
- `POTENTIAL` means only a mapped coastal feature and regional context exist. The UI must say it is a potential point and not claim a species is present there.
- Active/security harbour areas carry warnings or a hard block.
- Kerpe Kayalıkları is explicitly unsuitable for beginners despite stronger fishing evidence.
- Seasonal swimming areas require on-site checks and should not be recommended during crowded use.

The seed is intentionally regional and conservative. Community feedback, access review and regulation review are required before any promotion to `VERIFIED`.
